# App languages

The app ships in Indonesian (default), English (US and UK), Japanese, Spanish
and Simplified Chinese. Users can also follow the system language. The
language can be picked from the globe button at the bottom of the setup
wizard's welcome page, later in **Settings → App language**, and, on
Android 13+, in the system's per-app language settings. Both in-app entry
points open the same `LanguageSheet`. On Android 13+ the change is applied
in place (no activity restart) and the content fades to the new language;
see "Language switching" in setup-and-diagnostics.md.

## How it works

- **Per-app locale.** `ui/locale/AppLocale.kt` holds the per-app locale.
  - Android 13+ stores it through `LocaleManager`.
  - Android 12 keeps it in a private preference and wraps each Activity and
    Service context.
- **Language list.** `AppLanguage` lists the shipped languages. Its tags must
  match `res/xml/locales_config.xml`; `AppLanguageTest` checks this.

## Where the text lives

All user-facing text is in string resources, one file per area:
`res/values/strings_<area>.xml`. The areas are common, profiles, setup,
tweaks, dashboard, monitor, fps, usage, system, settings and nav.

| Language | Folder |
|---|---|
| Indonesian (default) | `values/` |
| English (US) | `values-en/` |
| English (UK) | `values-en-rGB/`, holding only the strings whose British wording differs |
| Japanese | `values-ja/` |
| Spanish | `values-es/` |
| Simplified Chinese | `values-zh-rCN/` |

Lint's `MissingTranslation` check fails the build when a language lacks a key.

## Writing code that shows text

- **In composables,** use `stringResource(R.string.key, args)`.
- **Outside composables** (ViewModels, message builders, input validation),
  return `core/text/UiText.kt`. The UI resolves it with `.asString()`.
  Unit tests compare `UiText` values, or render them with the test-only
  `debug()` helper.
- **Engine and protocol text is not translated.** This covers zperfd/zkfctl
  error details, sysfs values and identifiers. It is shown after a localized
  reason, as `UiText.Raw`.
- **Placeholders are positional** (`%1$s`, `%2$d`), so translations can
  reorder them. Avoid gluing translated fragments into a sentence; use one
  format string per sentence.

## Adding a language

1. Add an entry to `AppLanguage`, with the endonym as its label.
2. Add the same tag to `res/xml/locales_config.xml`.
3. Create `values-<qualifier>/strings_*.xml` with every translatable key.
4. Add the folder to the check in `tests/foundation_check.sh`.

## Setup-wizard animations

The Lottie files in `res/raw/setup_*.json` are generated by
`tools/lottie/gen_setup_animations.py`. Change the generator, never the JSON,
and regenerate:

```
python3 tools/lottie/gen_setup_animations.py
```

Fills and strokes are named after Material colour roles, and the gradient
strokes are named `brandGradient`. The wizard maps them to the active colour
scheme and the brand gradient at runtime, so the animations follow dynamic
colour and dark theme. When animations are turned off in system settings, the
wizard shows a still frame. `tests/foundation_check.sh` fails when the
committed JSON differs from the generator output.
